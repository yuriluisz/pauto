# pauto Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `pauto.exe`, a lightweight, zero-dependency Windows system tray app that automatically pauses Spotifast when a desktop browser starts playing media and resumes it once all browser media stops (only if `pauto` paused it).

**Architecture:** Split into a pure C# 5 logic core (`src/AutoPauseLogic.cs`) containing session classification and the auto-pause state machine, and a thin native Windows shell (`src/Program.cs`) bridging WinRT System Media Transport Controls (`Windows.Media.Control`) onto the WinForms UI thread with a system tray icon and startup registry toggle. Compiled directly with Windows' built-in `.NET Framework 4.x` `csc.exe` and tested via a standalone C# test runner (`tests/AutoPauseLogicTests.cs`) driven by `build.ps1`.

**Tech Stack:** C# 5.0 (`.NET Framework 4.x` built-in `csc.exe`), WinRT `Windows.Media.Control` (SMTC via `Windows.Media.winmd` + `Windows.Foundation.winmd` + `System.Runtime.WindowsRuntime.dll`), `System.Windows.Forms` (`NotifyIcon`, `Timer`), `Microsoft.Win32.Registry`, PowerShell (`build.ps1`).

## Global Constraints

- Target OS: Windows 10 / 11 with built-in `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe` (C# 5.0 syntax only — no C# 6+ string interpolation, null-conditional `?.`, expression-bodied members, `nameof`, or inline `out var`).
- Zero external runtime or build dependencies (no NuGet, no `.NET SDK`, no browser extension, no Spotify API/OAuth).
- Executable output: `dist/pauto.exe` (ignored by git).
- Single-instance mutex: `Local\pauto-single-instance` (second launch exits silently).
- Pause latency: `0ms` (immediate on browser rising edge).
- Resume debounce: `ResumeDebounceMs = 350` (anti-seek-flicker on browser falling edge).
- Startup registry key: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` value name `pauto`.
- Tray copy in Brazilian Portuguese matching user preferences.

```powershell
param(
    [switch]$TestOnly
)

$ErrorActionPreference = 'Stop'

$root = Split-Path -Parent $MyInvocation.MyCommand.Path
$distDir = Join-Path $root 'dist'
$csc = 'C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe'
$fxDir = 'C:\Windows\Microsoft.NET\Framework64\v4.0.30319'
$winMdDir = 'C:\Windows\System32\WinMetadata'

if (-not (Test-Path $csc)) {
    throw "C# compiler not found at $csc"
}

if (-not (Test-Path $distDir)) {
    New-Item -ItemType Directory -Path $distDir | Out-Null
}

$logicSrc = Join-Path $root 'src\AutoPauseLogic.cs'
$testSrc = Join-Path $root 'tests\AutoPauseLogicTests.cs'
$testExe = Join-Path $distDir 'pauto-tests.exe'

Write-Host 'Compiling unit tests...'
& $csc /nologo /target:exe /warnaserror /out:$testExe $logicSrc $testSrc
if ($LASTEXITCODE -ne 0) {
    exit $LASTEXITCODE
}

Write-Host 'Running unit tests...'
& $testExe
if ($LASTEXITCODE -ne 0) {
    exit $LASTEXITCODE
}

if ($TestOnly) {
    exit 0
}

$programSrc = Join-Path $root 'src\Program.cs'
$appExe = Join-Path $distDir 'pauto.exe'

Write-Host 'Compiling dist\pauto.exe...'
& $csc /nologo /target:winexe /optimize+ /warnaserror `
    /out:$appExe `
    "/r:$fxDir\System.dll" `
    "/r:$fxDir\System.Core.dll" `
    "/r:$fxDir\System.Drawing.dll" `
    "/r:$fxDir\System.Windows.Forms.dll" `
    "/r:$fxDir\System.Runtime.dll" `
    "/r:$fxDir\System.Threading.Tasks.dll" `
    "/r:$fxDir\System.Runtime.WindowsRuntime.dll" `
    "/r:$winMdDir\Windows.Media.winmd" `
    "/r:$winMdDir\Windows.Foundation.winmd" `
    $logicSrc $programSrc

if ($LASTEXITCODE -ne 0) {
    exit $LASTEXITCODE
}

Write-Host "Build succeeded: $appExe"
```

- [ ] **Step 1: Create initial failing stub `src/AutoPauseLogic.cs` and complete unit tests `tests/AutoPauseLogicTests.cs` (RED)**

Write stub `src/AutoPauseLogic.cs` with the public signatures returning default/stub values (`SessionKind.Other`, `PlaybackAction.None`, no-op notifications), and write `tests/AutoPauseLogicTests.cs` testing:
1. `SessionClassifier.Classify`: Spotifast (`spotifast.exe`, `Spotifast`, `com.spotifast.app`), browsers (`chrome.exe`, `MSEdge`, `brave.exe`, `opera.exe`, `firefox.exe`, `308046B0AF4A39CB`, `zen.exe`, `vivaldi.exe`, `arc.exe`), and non-browsers (`vlc.exe`, `Discord.exe`, `Telegram.exe`, `null`, `""`).
2. Browser starts playing while Spotifast plays -> `PauseSpotifast`; after `NotifyPauseSucceeded()`, browser stops -> `ScheduleResume`; timer elapses -> `ResumeSpotifast` and `PausedByUs == false`.
3. Spotifast manually paused before browser plays -> browser plays (`None`), browser stops (`None`), never auto-resumes.
4. Transient pre-pause SMTC event (Spotifast still reports `Playing` right after `NotifyPauseSucceeded()`) does NOT clear `PausedByUs`; once Spotifast reports `Paused`, later manual resume (`Playing` while browser still plays) DOES clear `PausedByUs` and does NOT re-pause Spotifast.
5. Multiple browser tabs: `anyBrowserPlaying` stays `true` -> `None`; only schedules resume when `anyBrowserPlaying` drops to `false`.
6. Anti-seek flicker: browser stops (`ScheduleResume`) then resumes within debounce (`CancelPendingResume`) while keeping `PausedByUs == true`; later browser stops -> `ScheduleResume` -> timer elapses -> `ResumeSpotifast`.
7. User manually resumes Spotifast during the 350ms pending resume window -> `CancelPendingResume` and clears `PausedByUs`.
8. Spotifast closes before resume timer elapses -> timer elapses returns `None` and clears `PausedByUs`.
9. Pause command fails (`NotifyPauseFailed()`) -> `PausedByUs` stays `false`, browser stop does not schedule resume.
10. `SetEnabled(false)` cancels pending resume, clears `PausedByUs`, and ignores subsequent browser play events; `SetEnabled(true)` resumes clean tracking without retroactive resume.

### Task 3: Windows SMTC Monitor & System Tray App (`src/Program.cs`)

**Files:**
- Create: `src/Program.cs`

**Interfaces:**
- Consumes: `Pauto.SessionKind`, `Pauto.PlaybackAction`, `Pauto.SessionClassifier`, `Pauto.AutoPauseController` from `src/AutoPauseLogic.cs`.
- Produces: `dist/pauto.exe` Windows tray application.

- [ ] **Step 1: Implement `src/Program.cs`**

Contains focused internal classes in `namespace Pauto`:
- `SessionSnapshot`: immutable DTO (`AppId`, `Status`, `Kind`) for diagnostics.
- `SmtcBridge`:
  - Initializes `GlobalSystemMediaTransportControlsSessionManager.RequestAsync()`.
  - Hooks `SessionsChanged` and per-session `PlaybackInfoChanged` (cleanly unsubscribing removed sessions on refresh).
  - Marshals all change notifications to a supplied UI-thread callback via `Control.BeginInvoke`.
  - Computes `(anyBrowserPlaying, spotifastPlaying, spotifastExists)` across all live sessions.
  - Executes `PauseSpotifastAsync()` (calls `TryPauseAsync()`, falling back once to `TryTogglePlayPauseAsync()` only if `TryPauseAsync()` returns `false` while status is still `Playing`) and `ResumeSpotifastAsync()` (calls `TryPlayAsync()`, falling back once to `TryTogglePlayPauseAsync()` only if `TryPlayAsync()` returns `false` while status is still `Paused`).
  - Wraps WinRT operations safely against `COMException` / `ObjectDisposedException` / `InvalidOperationException`.
  - Exposes `GetSnapshots()` for the tray diagnostics dialog.
- `StartupManager`:
  - Reads/writes `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` value `pauto` quoted to `Application.ExecutablePath`.
- `TrayIconFactory`:
  - Draws crisp 16x16 icons via `System.Drawing` (`Bitmap` + `Graphics` + `Icon.FromHandle` + `DestroyIcon` cleanup) for 3 states: Monitoring (green), Spotifast Paused by pauto (amber), Disabled (gray).
- `TrayApplicationContext : ApplicationContext`:
  - Hidden `Control` for safe UI-thread marshalling (`CreateHandle()`).
  - `System.Windows.Forms.Timer` (`Interval = AutoPauseController.ResumeDebounceMs`).
  - `NotifyIcon` with `ContextMenuStrip`:
    - Status item (disabled display label)
    - `Ativo` (toggle)
    - `Iniciar com o Windows` (toggle)
    - `Ver sessões de mídia` (popup showing live SMTC `SourceAppUserModelId`, classification, and playback status)
    - `Sair`
  - Cleans up icons, timer, and SMTC subscriptions on exit.
- `Program.Main`:
  - `[STAThread]`, acquires `Local\pauto-single-instance` `Mutex` (exits silently if already running), runs `Application.Run(new TrayApplicationContext())`.
